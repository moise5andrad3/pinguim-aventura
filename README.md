# Pinguim Aventura

Jogo web para celular em estilo anos 80, com um pinguim como protagonista, feito para uso em
família. Inspirado nas mecânicas de dois clássicos de 1983, Antarctic Adventure e Frostbite, com
arte, som e nomes originais.

## Status

Em planejamento. Os documentos de decisão (brainstorming, ADR de plataforma, PRD e arquitetura)
serão registrados em `docs/`.
